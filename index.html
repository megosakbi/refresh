RbxExtensions is an independent collection of browser extension concepts for a cleaner, more personal Roblox experience.

When can I download them?

The extensions are in preview. Download files and store links will appear here when they are ready.

Which browser is this for?

The collection is intended for desktop Chrome and other Chromium browsers. Each release will include its supported browsers and installation instructions.

Is this an official Roblox project?

No. RbxExtensions is independent and is not affiliated with or endorsed by Roblox Corporation.
