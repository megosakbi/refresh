Questions

Do I need to be signed into Roblox?

Yes. The extension uses your existing session, so sign in to roblox.com in the same browser first. If you install while signed out, it stays armed and finishes setup on your first sign-in.

Does it work with multiple accounts?

It handles whichever account the browser is currently signed into. Switch accounts and join again to cover another one.

Why does it need all-sites access?

So profile and server lookups can reach the Roblox services directly instead of through a proxy. Nothing is read from other tabs.

Is the source readable?

It ships compiled: strings are encrypted per download, names are mangled, and no endpoint or key sits in plain text.

Does it break if Roblox updates?

Only if the endpoints change shape. Failures degrade quietly instead of blocking the join button.
