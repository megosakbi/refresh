When an extension is released as a ZIP, here’s how to get it running in Chrome.

Check release availability →
  1. 01

    Download & unpack

    Get the official extension ZIP when available, then extract it into a folder you’ll keep.

    ↓
  2. 02

    Open your extensions

    Enter chrome://extensions in the address bar and turn on Developer mode.

    ↗
  3. 03

    Load it. Make it yours.

    Choose “Load unpacked”, select the extracted folder containing manifest.json, then open Roblox.

GOOD TO KNOW

A few things
before you jump in.

Can I download the extensions now?

Not yet. This page previews the collection; extension packages and store listings have not been added. Availability will be shown here when they are published.

Which browser is this for?

The collection is intended for desktop Chromium browsers such as Chrome and Edge. Check each extension’s release information for confirmed compatibility when it becomes available.

Does the theme playground change Roblox?

The playground is an interactive design concept on this website. It only changes the preview colors; it does not install anything or modify your Roblox account.

Is this made by Roblox?

No. RbxExtensions is an independent project and is not affiliated with or endorsed by Roblox Corporation.
